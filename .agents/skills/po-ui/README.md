# Skills de Agente PO-UI

Uma coleção de skills de agente IA para o ecossistema **PO-UI** da TOTVS (`@po-ui/ng-components`), a biblioteca de componentes Angular para aplicações corporativas.

---

## Skills Disponíveis

| Skill | Descrição |
|-------|-----------|
| [po-ui-guide](po-ui-guide/SKILL.md) | Guia completo para geração de código Angular com PO-UI. Cobre componentes de formulário, tabelas, páginas (po-page-list, po-page-edit, po-page-detail, po-page-dynamic-*), serviços (PoNotification, PoDialog) e padrões CRUD completos. |

---

## Documentação Local

A documentação completa dos componentes está disponível em:

```
po-ui/doc/llms-generated/    → Documentação de cada componente (inputs, outputs, métodos)
po-ui/doc/sources/llms.txt   → Índice de todos os componentes
```
