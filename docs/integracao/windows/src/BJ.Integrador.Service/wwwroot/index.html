Resumo Operacional do Serviço

O serviço BJ.Integrador roda em segundo plano coletando e processando registros das tabelas de fila do Protheus sem alterar o dicionário do ERP. O isolamento por empresa é reforçado por conexão própria e parâmetros hierárquicos.

⚙️ Configurações de Conexão e Serviço

Gerencie as Connection Strings do SQL Server e parâmetros do Monitor visual. Altera o arquivo appsettings.json.

🔒 Cofre de Credenciais (Criptografia DPAPI)

Criptografe tokens e senhas de API REST utilizando a proteção do Windows Server (DPAPI escopo máquina). Grave a string gerada na coluna integ.Empresa.CredencialCriptografada.
